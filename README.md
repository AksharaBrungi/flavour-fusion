# 🍽️ Flavour Fusion – AI-Powered Food Blogging Platform

Welcome to **Flavour Fusion**, a smart and interactive food blogging platform designed to make cooking more creative and fun. This project uses Artificial Intelligence to generate personalized recipes based on ingredients provided by the user. Whether you’re a foodie, beginner cook, or someone confused about “what to cook today,” Flavour Fusion helps you instantly discover delicious recipe ideas.

---

## ✨ About the Project

Flavour Fusion was developed to simplify recipe discovery using AI. Instead of searching endlessly online, users can simply enter available ingredients and receive AI-generated recipes within seconds.

The project combines modern frontend technologies with the power of Google Gemini AI to create a smooth and intelligent user experience.

---

## 🚀 Features

* 🤖 AI-generated recipes using Gemini API
* 🥗 Ingredient-based recipe suggestions

## ⚙️ Installation Guide

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/flavour-fusion.git
cd flavour-fusion
```

### Step 2: Install Dependencies

```bash
npm install
```

### Step 3: Add Environment Variables

Create a `.env.local` file and add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

You can generate your API key from:

[https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)

---

## ▶️ Run the Project

Start the development server:

```bash
npm run dev
```

The application will run at:

```bash
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```

## 💡 How It Works

1. User enters ingredients or uploads a food image.
2. The system sends the data to Gemini AI.
3. AI analyzes the ingredients.
4. Personalized recipes are generated instantly.
5. Recipes are displayed with cooking instructions and details.
